# Поднебесная — панель путешественника

Практическое задание №2 по Web-дизайну. Тема: путешествие в Китай.

## Запуск
Чистые HTML/CSS/JavaScript, без сборки и платных библиотек.
Запустить HTTP-сервер в папке с index.html: `python -m http.server 8000`.
Открыть http://localhost:8000. Открытие через file:// не подходит для ES-модулей.

## Возможности
Три независимых виджета: список дел, погода, курс юаня. Каждый можно добавить,
свернуть и удалить. Повторное добавление запрещено. Задачи можно добавлять,
отмечать и удалять. Набор карточек, сворачивание, задачи, город, валюта и сумма
сохраняются в localStorage. При повреждённых данных панель загружает начальное
состояние; запрет сохранения отображается пользователю. После обновления погода
и курсы запрашиваются заново. Запросы отменяются при удалении карточек и через
12 секунд ожидания. Ошибка одной карточки не влияет на остальные. Состояния:
загрузка, результат, ошибка с повтором. Нет вымышленных актуальных данных.
Адаптивная сетка, управление с клавиатуры, подписанные кнопки, отключение анимации.

## Источники API
1. Open-Meteo: https://open-meteo.com/en/docs
   https://api.open-meteo.com/v1/forecast?latitude=39.9042&longitude=116.4074&current=temperature_2m,relative_humidity_2m,weather_code,wind_speed_10m&timezone=Asia%2FShanghai
2. Frankfurter: https://frankfurter.dev/
   https://api.frankfurter.dev/v1/latest?base=EUR&symbols=CNY
   Доступны EUR → CNY и USD → CNY. API без секретных ключей. Дата курса видна
   в карточке; это справочный курс, а не предложение обмена.

## Архитектура
components.js: UIComponent, ToDoWidget, NetworkWidget, WeatherWidget,
CurrencyWidget. dashboard.js: Dashboard и localStorage. main.js:
инициализация панели и анимации. Все файлы — ES-модули.
Иллюстрация гор и фарфоровые пиалы созданы в SVG. Шрифты Manrope и Prata
подключены из Google Fonts; при недоступности используются системные шрифты.

## Проверка вручную
1. Добавить задачу, отметить и удалить; обновить страницу и проверить сохранение.
2. Свернуть карточку и обновить; удалить все карточки и обновить — панель пуста.
3. Пять раз удалить и добавить каждый виджет: один клик добавляет одну задачу.
4. Сменить город и базовую валюту; проверить значения и дату из ответов API.
5. Отключить интернет: у сетевых карточек появится ошибка не позднее 12 секунд.
   Список дел продолжает работать. Включить сеть и нажать «Повторить».
6. Проверить ширины 375, 768 и 1440 px, клавиатуру и кнопку «Пиалы».
